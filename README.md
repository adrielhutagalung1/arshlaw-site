# arshlaw-site

Situs ARSH & Partners Law Office (www.arshlaw.id). Halaman statis, tanpa proses build di hosting.

- Ubah isi di `build.py`, lalu jalankan `python3 build.py` untuk menulis ulang halaman HTML (ID di root, EN di `en/`).
- Gaya ada di `assets/style.css`.
- Teks bertanda `[ISI DARI ADVOKAT: ...]` masih menunggu isi dari advokat.
- Hosting: Cloudflare Pages, output directory `/`, tanpa build command.
